# ExamPic AI (starter project)
Open this folder in Android Studio, let Gradle sync, run on a device.
Included: Gradle setup, home screen, core model/OCR/Layout Lock/undo (core/ExamPicCore.kt), MediaStore exporter.
Not yet done: camera/gallery wiring, image cleanup (OpenCV), editor canvas, Bangla/Arabic/Urdu OCR engine, math OCR, DOCX, Room storage, multi-page UI.
This starter has not been compiled; expect minor fixes on first sync.
